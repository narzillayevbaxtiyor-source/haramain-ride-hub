# Haramain Gateway

Build the first foundation and landing page of a professional airport transfer platform called Haramain 2 Airport.



IMPORTANT:



- The attached image is a DESIGN REFERENCE ONLY.

- Do NOT copy the image, text, logo, branding, or exact layout.

- Use it only as inspiration for the visual hierarchy, spacing, composition, premium feeling, typography balance, cards, buttons, and overall UI quality.

- Create an original design for Haramain 2 Airport.

- Do not add unnecessary features or pages yet.

- Do not modify or implement the booking system, driver dashboard, admin panel, or payment system in this step.

- Focus on creating a strong reusable design foundation and the first landing page.



1. BRAND



Brand name:

Haramain 2 Airport



The platform connects passengers traveling from Makkah and Madinah with drivers providing airport transfers.



Main service concept:

Makkah & Madinah → Airports



Supported destination airports:



- Jeddah Airport

- Madinah Airport

- Taif Airport



The design should feel:



- premium

- trustworthy

- modern

- clean

- fast

- professional

- suitable for Saudi Arabia

- comfortable for Muslim travelers and Umrah travelers



Avoid making the design overly decorative or overly religious.

Use subtle Saudi/Islamic visual influence only where appropriate.



2. LANGUAGES



The website must support exactly these three languages:



1. 🇷🇺 Russian

2. 🇺🇿 Uzbek

3. 🇸🇦 Arabic



Create a language selector in the header.



Default language:

Uzbek



IMPORTANT:

Arabic must support a complete RTL layout.



When Arabic is selected:



- page direction becomes RTL

- navigation becomes RTL

- cards and content alignment adapt correctly

- buttons and icons remain visually balanced

- spacing must remain professional



Do not simply translate the page later. Build the UI architecture so multilingual content is supported from the beginning.



3. RESPONSIVE DESIGN



Build mobile-first.



The website must look excellent on:



- Android phones

- iPhones

- tablets

- desktop

- large desktop screens



Most users will likely use mobile phones, so mobile UX is extremely important.



Use responsive layouts rather than fixed desktop layouts.



4. HEADER



Create a clean premium header.



Include:



- Haramain 2 Airport logo/brand

- language selector

- simple navigation structure



Keep the header minimal.



Do not add unnecessary menu items yet.



On mobile:



- use a clean compact header

- language selector must remain easy to access

- use a hamburger menu only if necessary



5. HERO SECTION



Create a visually impressive but clean hero section.



The hero should communicate immediately:



Haramain 2 Airport



and the concept:



Easy Airport Transfers from Makkah & Madinah



Use the attached image as visual inspiration only.



The hero should have:



- strong headline

- short supporting text

- beautiful transportation/travel visual

- premium spacing

- strong visual hierarchy



Do not overcrowd the hero.



6. TWO MAIN USER PATHS



This is the most important part of the first page.



Create two large, visually distinct cards/buttons:



CARD 1 — PASSENGER



Uzbek:

Yo‘lovchiman



Supporting text:

Aeroportga mashina buyurtma qilish



Use an elegant illustration/sticker concept showing:



- Muslim traveler / pilgrim

- luggage

- vehicle/travel context



CARD 2 — DRIVER



Uzbek:

Haydovchiman



Supporting text:

Haydovchi sifatida qo‘shilish



Use an elegant illustration/sticker concept showing:



- professional driver

- car

- transportation context



The two cards should be extremely easy to understand.



On desktop:



- display them side-by-side



On mobile:



- stack them vertically



Both cards must have clear click/hover/tap states.



Do NOT build their destination pages yet.

For now, only create the UI entry points/routes/placeholders necessary for later development.



7. POPULAR ROUTES SECTION



Below the main CTA cards, create a clean section:



Popular Airport Transfers



Show route cards for:



- Makkah → Jeddah Airport

- Makkah → Madinah Airport

- Makkah → Taif Airport

- Madinah → Jeddah Airport

- Madinah → Taif Airport



Use elegant airport/transport icons or subtle illustrations.



Do not add fake prices.



Do not invent travel times.



8. WHY HARAMAIN 2 AIRPORT



Create a simple trust section.



Use 4 concise benefits:



- Easy booking

- Choose your driver

- Private & shared rides

- Competitive prices



Use clean icons.



Do not make unsupported claims such as "100% safe", "best price guaranteed", "licensed", "verified drivers", etc.



9. VISUAL STYLE



Use the attached reference image to guide the visual quality.



The final design should feel like a professional modern travel/transportation startup.



Prioritize:



- excellent typography

- generous spacing

- rounded but professional cards

- subtle shadows

- elegant buttons

- strong visual hierarchy

- excellent mobile UX

- smooth but lightweight animations



Avoid:



- excessive gradients

- excessive animations

- excessive shadows

- clutter

- too many colors

- cheap-looking taxi-app aesthetics

- excessive Islamic patterns

- generic template appearance



Create a coherent design system that can be reused throughout the entire application.



10. COLOR SYSTEM



Create a professional premium color palette suitable for:



- Saudi Arabia

- airport transportation

- travel

- trust



Keep the palette restrained.



Define reusable design tokens for:



- primary

- secondary

- background

- surface

- text

- muted text

- border

- success

- warning

- error



Do not randomly choose different colors on different components.



11. TYPOGRAPHY



Choose a modern highly readable font system supporting:



- Latin

- Cyrillic

- Arabic



The same typography system should work professionally in Uzbek, Russian and Arabic.



Arabic typography must remain readable and elegant.



12. FOOTER



Create a simple professional footer containing:



Haramain 2 Airport



Links/placeholders for:



- Passenger

- Driver

- Popular Routes

- FAQ

- Contact



And the language selector.



Do not add unnecessary legal/company information yet.



13. TECHNICAL FOUNDATION



Create reusable components.



Examples:



- Header

- LanguageSelector

- HeroSection

- UserTypeCard

- RouteCard

- BenefitCard

- Footer



Use a clean component architecture so future pages can reuse the same design system.



Prepare the project for:



- authentication later

- passenger booking flow later

- driver registration later

- admin dashboard later

- multilingual content

- Arabic RTL

- payment integration later



Do NOT implement those systems now.



14. SEO FOUNDATION



For the home page create:



Title:

Haramain 2 Airport | Makkah & Madinah Airport Transfers



Meta description:

Book airport transfers from Makkah and Madinah to Jeddah, Madinah and Taif airports. Choose private or shared transportation with local drivers.



Use proper:



- semantic HTML

- H1

- H2

- accessible buttons

- alt text

- mobile responsive structure



Create the foundation so sitemap and additional SEO pages can be added later.



15. IMPORTANT DEVELOPMENT RULE



Before adding any new feature, keep the current design system consistent.



Do not redesign the reference image literally.



Build an ORIGINAL Haramain 2 Airport interface inspired by the attached reference.



Do not add features that were not requested in this prompt.



At the end, make sure the landing page is fully responsive and visually polished on both mobile and desktop.
